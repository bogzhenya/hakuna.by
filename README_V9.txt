HAKUNA TRAVEL — обновление по согласованному ТЗ.

Откройте index.html в браузере. Испания добавлена как отдельная страница с временной заглушкой.
Изображения для Болгарии, Венгрии, Германии, Греции, Италии, Польши, Румынии и Франции взяты из предоставленного архива «графика hakuna.zip». Для Австрии, Нидерландов и Швейцарии использованы доступные ранее фирменные изображения. Для США и Канады временно оставлены заглушки, так как отдельных изображений этих стран в предоставленном архиве не обнаружено.
